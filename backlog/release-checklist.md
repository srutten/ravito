# Checklist de livraison

## Avant gel

- backlog du lot terminé ;
- bugs critiques fermés ;
- documentation à jour ;
- migration validée ;
- dépendances revues.

## Sécurité

- scan de secrets ;
- scan de dépendances ;
- MFA testé ;
- autorisations revues ;
- positions masquées ;
- audit vérifié ;
- comptes de test supprimés.

## Données

- sauvegarde ;
- restauration testée ;
- seed absent de production ;
- politiques de rétention ;
- URLs signées.

## Fonctionnel

- parcours demande ;
- proposition ;
- affectation ;
- départ ;
- arrivée ;
- clôture ;
- incident ;
- annulation.

## Technique

- build ;
- tests ;
- smoke tests ;
- alertes ;
- dashboards ;
- files ;
- feature flags ;
- rollback.

## Opérationnel

- responsables ;
- support ;
- procédure panne ;
- procédure compromission ;
- procédure violation ;
- communication utilisateur.

## Après livraison

- surveiller ;
- vérifier erreurs ;
- vérifier files ;
- vérifier notifications ;
- confirmer avec les utilisateurs pilotes ;
- documenter les écarts.
