# Protection des données et RGPD

## Principes

- Finalité déterminée.
- Minimisation.
- Exactitude.
- Limitation de conservation.
- Sécurité.
- Transparence.
- Responsabilité.

## Catégories de données

- identité ;
- coordonnées ;
- appartenance à une organisation ;
- localisation ;
- documents professionnels ;
- historique de mission ;
- données techniques ;
- traces de sécurité.

## Données à éviter

- données de santé ;
- détails sur les victimes ;
- informations familiales ;
- opinions ;
- pièces d'identité non nécessaires ;
- suivi permanent.

## Finalités

- gestion des comptes ;
- qualification des ressources ;
- coordination des missions ;
- sécurité ;
- preuve ;
- amélioration du service ;
- gestion des incidents.

## Rétention indicative à valider juridiquement

- comptes actifs : durée du compte ;
- comptes supprimés : délai technique limité ;
- documents : jusqu'à expiration plus délai justifié ;
- missions : durée définie par la gouvernance ;
- audit de sécurité : durée proportionnée ;
- notifications : durée courte ;
- positions précises : uniquement tant que nécessaire.

## Droits

Prévoir :

- accès ;
- rectification ;
- suppression lorsque applicable ;
- limitation ;
- export ;
- opposition lorsque applicable ;
- contact du responsable.

## Mesures

- registre des traitements ;
- analyse d'impact avant pilote réel ;
- contrats avec sous-traitants ;
- hébergement adapté ;
- gestion des violations ;
- procédures de demande de droits ;
- contrôle des exports ;
- données de test anonymisées.

## Attention

Ce document est un cadrage technique et produit. La base légale, les durées et les responsabilités doivent être validées par un professionnel compétent avant mise en service réelle.
